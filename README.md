# Kedr-lite — лабораторная работа №10

## Описание проекта

Проект предназначен для автоматизированного тестирования демонстрационного приложения Kedr-lite с использованием Playwright.

## Используемые технологии

- Node.js
- JavaScript
- Playwright
- Chromium

## Структура проекта

- kedr_lite.html — тестируемое приложение.
- tests/payment.spec.js — автоматизированные тесты оплаты.
- package.json — зависимости и настройки проекта.
- package-lock.json — зафиксированные версии зависимостей.
- .gitignore — исключения для Git.

## Установка и запуск

1. Установить зависимости:

   npm install

2. Установить браузер Chromium:

   npx playwright install chromium

3. Запустить тесты:

   npx playwright test

## Проверяемые сценарии

### 1. Успешная оплата

Проверяется оплата на сумму 500 рублей. Ожидаемый результат — сообщение «Оплата прошла» и корректное отображение суммы.

### 2. Проверка некорректной суммы

Проверяется ввод abc вместо числовой суммы.

Ожидаемое поведение — приложение должно отклонить некорректную сумму.

Фактическое поведение — приложение сообщает об успешной оплате с NaN ₽.

Тест специально фиксирует обнаруженный дефект и должен завершаться ошибкой до исправления приложения.

## Результаты тестирования

- Тест успешной оплаты — Passed.
- Тест некорректной суммы — Failed (обнаружен дефект приложения).
